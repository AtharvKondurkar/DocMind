# DocMind

## AI-Powered Document Analysis & Intelligent Notes Generation

DocMind is a Python-based AI application built with Streamlit and Google Gemini. It provides two primary workflows: AI-powered document image analysis and summarization, and comprehensive topic-wise notes generation.

Users can upload document images, provide optional instructions, and receive structured summaries generated by Gemini. The application also allows users to enter an academic topic and generate detailed study notes in multiple languages.

---

## Features

### Document Analysis

- Upload document images in JPG, JPEG, or PNG format.
- Provide an optional prompt or instruction for analysis.
- Analyze uploaded images using Google Gemini.
- Generate structured document summaries.
- Highlight key points and important information.
- Download generated summaries as `.txt` files.

### AI Notes Generator

- Enter any academic or general topic.
- Generate comprehensive, structured notes using Google Gemini.
- Supports multiple output languages:
  - English
  - Hindi
  - Spanish
  - French
  - German
- Designed for university-level study and reference.
- Download generated notes as `.txt` files.

### Fallback Content

For supported topics, DocMind includes predefined educational content that can be used when Gemini generation is unavailable.

This provides a fallback experience while keeping the application functional during API or connectivity issues.

### Environment-Based API Configuration

- Gemini credentials are loaded through environment variables.
- API keys are not hard-coded into the application.
- `.env` is excluded from Git using `.gitignore`.
- `.env.example` is provided as a safe configuration template.

# Getting Started

## Prerequisites

Before running DocMind locally, make sure you have:

- Python 3.9 or newer
- pip
- Git
- A valid Google Gemini API key

An internet connection is required for Gemini API requests.

---

## 1. Clone the Repository

Clone the repository from GitHub:

```bash
git clone https://github.com/AtharvKondurkar/DocMind.git
```

Move into the project directory:

```bash
cd DocMind
```

---

## 2. Create a Virtual Environment

Creating a virtual environment keeps project dependencies isolated from your system Python installation.

### Windows

```powershell
python -m venv venv
```

Activate the environment:

```powershell
venv\Scripts\activate
```

After activation, your terminal should show something similar to:

```text
(venv) PS C:\...\DocMind>
```

### macOS / Linux

```bash
python3 -m venv venv
```

Activate the environment:

```bash
source venv/bin/activate
```

---

## 3. Install Dependencies

With the virtual environment activated, install the required packages:

```bash
pip install -r requirements.txt
```

The project currently uses:

```text
streamlit
google-generativeai
python-dotenv
Pillow
```

---

## 4. Configure the Gemini API

DocMind requires a Google Gemini API key for AI-powered generation.

Create a `.env` file in the project root:

```text
DocMind/
├── app.py
├── notes_app.py
├── requirements.txt
├── .env
└── ...
```

Add the following:

```env
GOOGLE_API_KEY=your_google_gemini_api_key_here
```

Replace the placeholder with your actual API key.

Do not commit the `.env` file to GitHub.

The repository includes `.env.example` as a safe configuration template.

---

## 5. Run the Application

Start the main Streamlit application:

```bash
streamlit run app.py
```

Alternatively:

```bash
python -m streamlit run app.py
```

Streamlit will start a local development server and display a URL similar to:

```text
Local URL: http://localhost:8501
```

Open the displayed URL in your browser.

# Configuration

DocMind reads the Gemini API key using `python-dotenv`.

The application expects the following environment variable:

```env
GOOGLE_API_KEY=your_api_key
```

The application loads the environment configuration at startup:

```python
from dotenv import load_dotenv
import os

load_dotenv()

api_key = os.getenv("GOOGLE_API_KEY")
```

This approach avoids placing API credentials directly inside the source code.

# Security Considerations

DocMind uses environment variables for API credentials.

### Store credentials locally

```text
.env
```

Store your API key locally in `.env`.

### Commit only the safe template

```text
.env.example
```

The example file contains only a placeholder and can safely be committed.

### Never hard-code credentials

Do not place an actual API key inside Python source files.

### Never commit `.env`

The repository's `.gitignore` contains:

```text
.env
.env.*
!.env.example
```

This prevents sensitive environment files from being included in future commits while keeping the safe example configuration available.

# Troubleshooting

## Streamlit command not found

Make sure the virtual environment is activated and dependencies are installed:

```bash
pip install -r requirements.txt
```

Then try:

```bash
python -m streamlit run app.py
```

---

## Gemini API errors

Verify that your `.env` contains:

```env
GOOGLE_API_KEY=your_actual_api_key
```

Also verify that:

- The API key is valid.
- Required Gemini API access is enabled.
- Your internet connection is working.
- The environment variable name is exactly `GOOGLE_API_KEY`.

---

## Application cannot find the API key

Make sure `.env` is located in the project root:

```text
DocMind/
├── .env
├── app.py
├── notes_app.py
└── requirements.txt
```

Restart Streamlit after modifying the environment configuration.

---

## Image upload problems

Make sure the uploaded document is one of the supported formats:

```text
JPG
JPEG
PNG
```

Large or corrupted image files may also cause processing issues.
